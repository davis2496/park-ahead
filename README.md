# Park Ahead

Check London parking before you set off: nearby car parks, kerbside rules at your arrival time, Congestion Charge and ULEZ.

Data: OpenStreetMap contributors (ODbL), TfL Open Data, postcodes.io, gov.uk bank holidays. Kerbside data is incomplete; the sign on the street always wins.

Run locally: `node server.js`, then open http://localhost:5173
